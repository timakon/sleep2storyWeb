# Страницы, запросы и внутренние ссылки

Проект структуры от 7 сентября 2026 года. Новые URL здесь предлагаются для будущей публикации; существующие маршруты проверены в sitemap.

## Минимальная структура

```text
/                                                        продукт / own-voice app
/guides/                                                 список материалов
  how-to-record-bedtime-stories/                          существующая запись целиком
  grandparents-record-stories-for-grandchildren/          существующая статья для внуков
  bedtime-stories-for-kids-calm-routine/                   существующий вечерний ритуал
  turn-your-bedtime-story-into-audio/                     новая тема 1: собственный текст → аудио
  bedtime-stories-when-a-parent-is-away/                   новая тема 2: отсутствие родителя
  recording-bedtime-stories-vs-ai-narration/               новая тема 3: различия способов
  family-story-prompts-for-kids/                          новая тема 4: создать семейный текст
```

Не нужны отдельные пустые разделы и посадочные для каждого синонима. Первые четыре новых материала достаточно добавить в существующий раздел Guides. Новая библиотека сказок/аудио оправдана только при появлении самих произведений и записей; пока не создавать пустой `/stories/`.

## Локализованные адреса

Сейчас английские материалы находятся в `/guides/`, русские — `/ru/guides/`, немецкие — `/de/ratgeber/`; остальные маршруты уже определены существующей сборкой. Сохранять эти соглашения и локализованные slugs. Не переименовывать опубликованные URL ради ключевого слова без реальной необходимости.

Для каждой опубликованной языковой версии — собственный canonical. Hreflang должен связывать эквивалентные реально опубликованные переводы, включая обратные ссылки и self-reference. Если новая серия сначала выходит на части языков, alternate-ссылки не должны указывать на отсутствующие переводы. Возможность такого поэтапного выпуска нужно отдельно проверить в сборке; в рамках исследования она не изменялась.

На главной достаточно одного EN-варианта до появления содержательных региональных отличий. Запросы США и Великобритании измерять раздельно, но не размножать одинаковые страницы. Google описывает языковые и региональные версии отдельно. [Официальная документация](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites?hl=en).

Рекомендация по обнаруженному автоматическому переключению `/` → `/ru/`: отдельно рассмотреть предложение языка с ручным выбором. Это не означает, что текущая главная закрыта для Google; HTML-ответ `/` доступен и содержит английский текст.
