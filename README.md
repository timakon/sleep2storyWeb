# Sleep2Story marketing site

Статический SEO-лендинг без runtime-зависимостей на 14 языках: английском,
русском, немецком, украинском, польском, сербском, французском, испанском,
итальянском, португальском, нидерландском, чешском, румынском и турецком.
Английский — основной язык на `/`; остальные локали используют отдельные
индексируемые URL. При первом посещении `/` браузер выбирает поддерживаемую
локаль; сохранённый ручной выбор имеет приоритет, а неизвестный язык остаётся
на английском. Прямые локализованные URL никогда не перенаправляются.

## Локальный запуск

```sh
uv run scripts/build.py
uv run scripts/check_site.py
node scripts/check_locale_redirect.mjs
node scripts/check_analytics.mjs
python3 -m http.server 4174 --directory dist
```

Открыть `http://localhost:4174/`, `/ru/`, `/de/`, `/uk/` или другой локализованный маршрут.

Исходники:

- `site/home.template.html` — общий шаблон локализованной страницы;
- `site/locales/*.properties` — переводы с обязательным равенством ключей;
- `variants/variants.css` — дизайн-система и адаптивные стили;
- `scripts/build.py` — production-сборка в `dist/`;
- `scripts/check_site.py` — маршруты, SEO, локаль ссылок, sitemap и ресурсы.

## Публикация

Сборка не использует публичные переменные окружения и не содержит секретов.
Минимальный вариант при существующем GitHub-репозитории — GitHub Pages с артефактом
`dist/`, custom domain `sleep2story.com` и HTTPS. Рабочая публикация идёт через
`git push public main`; workflow проверяет сборку и выкладывает её в GitHub Pages.

## Аналитика сайта

GA4 подключён с идентификатором `G-HXBT0T7YQM` через `assets/analytics.js`.
Уведомление и настройки есть на всех канонических страницах, переводы хранятся
в `site/analytics-locales/`. До разрешения посетителя Google tag не загружается.
Отказ запоминается, решение меняется кнопкой в подвале. Отзыв согласия удаляет
cookies GA и перезагружает страницу. Срок cookies и решения — до 180 дней;
рекламные функции и Google Signals выключены. Собственный backend не нужен.

UTM-метки сохраняются при выборе языка. Автоматический переход с `/` также
передаёт только внешний origin источника через временный `s2s_referrer`, который
убирается из адреса при загрузке. До согласия источник хранится только в памяти
страницы. В GA передаются адрес без фрагмента и только разрешённые UTM-параметры.
Не помещайте персональные данные в UTM-метки. Локальные проверки после согласия
помечаются `debug_mode`; автоматические проверки согласие не дают.

В GA4 источники доступны в отчёте «Привлечение трафика», страницы — в «Страницы
и экраны», проверка подключения — «В реальном времени». Поисковые запросы Google
смотрите в Search Console; её можно связать с этим ресурсом GA4. Аналитика
начинается с установки и согласия, прежние посещения не восстанавливаются.

Перед релизом приложения остаётся добавить ссылки магазинов. Форма ожидания
пока отсутствует; для неё потребуются backend и CORS. Полные Privacy Policy,
Terms и Impressum с реквизитами оператора ещё не опубликованы: уведомление об
аналитике не заменяет эти документы. Настройки хранения данных в кабинете GA4
задаются отдельно от срока cookies.
